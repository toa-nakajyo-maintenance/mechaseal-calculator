# メカシールセット寸法計算

整備基準書 共-005「メカニカルシール交換セット要領」に沿って、メカニカルシールのセット寸法を計算するアプリです。

公開URL: https://toa-nakajyo-maintenance.github.io/mechaseal-calculator/

## できること
- 中古摺り合わせ品と交換する場合のスリーブセット寸法の計算
- セット寸法が不明な場合（図面なし）の回転環セット寸法（⑥−⑦）の計算
- 作業手順（基準書）の確認

## オフラインで使う
一度ネットにつないで開き、ホーム画面に追加しておくと、圏外でも使えます。

## 更新のしかた
1. `index.html` を差し替える
2. `sw.js` の `CACHE` の番号を1つ上げる（例: `mechaseal-v1` → `mechaseal-v2`）

## 注意
- メカシールセット寸法は、必ず取扱説明書（有るもの）を参照のこと。
- ポンプ組立後、洩れテストは必ず実施のこと。
